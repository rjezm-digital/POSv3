# Printing POS System

Simple POS + Calculator + Digital Receipt for small printing businesses.

## Features
- Printing cost calculator
- POS payment (Cash / GCash)
- Digital receipt
- Mobile-friendly
- No backend needed

## How to Use
1. Upload files to GitHub
2. Enable GitHub Pages
3. Open the live link
4. Start selling

## Deployment
Works on:
- GitHub Pages
- Netlify
- Canva Code (paste index.html)
